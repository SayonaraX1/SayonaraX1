# POLARIS

POLARIS is the umbrella ecosystem for a local-first developer workspace focused on operational control, knowledge continuity, automation and recoverable workflows.

## Architecture

- **PolarisHub** — launcher, console and operational control.
- **Command Center** — knowledge core, recovery and continuity.
- **WidgetX** — desktop widgets and device state.
- **AxFlowZ** — AX workflow visualization and tooling.
- **zAgent** — local support and Zammad operations tooling.
- **DCL-Launcher / DCL-Bridge** — local and remote Desktop Commander connectivity helpers.

## Identity

The visual direction is dark, cyberpunk-inspired and high-contrast, using cyan, purple and magenta accents while prioritizing readability.

## Presentation assets

The approved POLARIS cover belongs under `assets/polaris-cover.png` when the original approved source is available. It should not be substituted automatically with a different capture or generated image.

## Separation of responsibilities

This repository is the public presentation layer for the ecosystem. Productive code remains in the individual project repositories; operational knowledge and recovery context remain in Command Center.
