# SayonaraX1

> Building practical developer tooling, automation and personal knowledge systems.

I like turning repetitive technical work into fast, visual and recoverable workflows — especially on Windows, PowerShell and local-first environments.

## What I build

- **Developer consoles & tooling** — persistent PowerShell workflows, Git helpers and keyboard-first interfaces.
- **Automation** — repeatable operational flows with validation, rollback awareness and evidence.
- **Desktop utilities** — lightweight tools and widgets focused on useful system state.
- **Knowledge systems** — structured operational memory, recovery and project continuity.
- **Enterprise workflow tooling** — helpers around business systems and technical support processes.

## Stack

## Working principles

- verified state over assumptions
- small reversible changes
- validation before commit
- clear recovery paths
- local-first when practical
- documentation that survives the original chat/session
